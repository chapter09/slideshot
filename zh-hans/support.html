支持

联系我们

请在 GitHub 上提交 issue（需要免费的 GitHub 账户）。请注明你的 iPhone 机型和 iOS 版本；如果显示异常，请附上截图。你也可以浏览已有的 issue。

没有出现幻灯片轮廓

请确保整张幻灯片（四个角）都在画面内。在昏暗的会场拍摄非常亮的投影时，请轻点幻灯片来对焦和测光；轮廓变绿时拍摄效果最好。

幻灯片被裁切或歪斜

打开该幻灯片，轻点“调整角点”按钮，然后拖动四个角。轻点“检测”可重新尝试自动检测。

幻灯片被归入了错误的演讲

在演讲页面中长按一张幻灯片并选择“从这里开始新演讲”，或在资料库中使用“选择”来合并演讲。你手动编辑过的标签不会被覆盖。

自动拍摄拍得太多或太少

在相机界面用 A 按钮关闭自动拍摄，改为手动拍摄，或在“设置”中更改。

所有内容都保存在你的 iPhone 上。请参阅隐私政策。
