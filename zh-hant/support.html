支援

聯絡我們

請在 GitHub 上建立 issue（需要免費的 GitHub 帳號）。請註明你的 iPhone 機型和 iOS 版本；如果畫面顯示異常，請附上螢幕截圖。你也可以瀏覽現有的 issue。

沒有出現投影片外框

請確認整張投影片（四個角）都在畫面內。在昏暗的會場拍攝非常亮的投影時，請點一下投影片來對焦和測光；外框變綠時拍攝效果最好。

投影片被裁切或歪斜

打開該投影片，點一下「調整角落」按鈕，然後拖移四個角。點一下「偵測」可重新嘗試自動偵測。

投影片被歸到錯誤的演講

在演講頁面中長按一張投影片並選擇「從這裡開始新演講」，或在資料庫中使用「選取」來合併演講。你手動編輯過的標籤不會被覆寫。

自動拍攝拍得太多或太少

在相機畫面用 A 按鈕關閉自動拍攝，改為手動拍攝，或在「設定」中更改。

隱私

所有內容都保存在你的 iPhone 上。請參閱隱私權政策。
